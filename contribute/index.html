    ¿Cómo contribuir con estos ejercicios?

    Descargá el ZIP y seguí uno de estos caminos para enviarlo al repositorio.

    Ya tengo un fork del repositorio
    1. Descargá el ZIP con el botón de arriba
    2. Extraelo en la carpeta new-exercises/ de tu fork
    3. Ejecutá python review.py (opcional — para revisar en localhost:5112)
    4. Ejecutá python import_exercises.py
    5. Hacé commit, push a tu fork, y abrí un PR
    unzip new-exercises.zip -d new-exercises/
python review.py          # (opcional) revisar en localhost:5112
python import_exercises.py
git add exercises/
git commit -m "Add new exercises"
git push
# Luego abrí un PR en GitHub desde tu fork
    No tengo un fork

    Primero hacé fork del repositorio en GitHub, después elegí cómo trabajar:

    Opción 1: GitHub Desktop (recomendado para principiantes)
    1. Instalá GitHub Desktop
    2. Hacé fork del repo: clickeá "Fork" en github.com/Tomy-Niepo/AstroDojo
    3. En GitHub Desktop: File → Clone Repository → seleccioná tu fork
    4. Extraé el ZIP descargado en la carpeta new-exercises/ dentro del repo clonado
    5. Abrí una terminal en esa carpeta y ejecutá: 
      pip install -r requirements.txt
python import_exercises.py
    6. En GitHub Desktop: vas a ver los archivos nuevos. Escribí un mensaje de commit y clickeá "Commit to main"
    7. Clickeá "Push origin"
    8. Clickeá "Create Pull Request" — se abre GitHub en el navegador para enviar tu PR
    Opción 2: Terminal 
    # 1. Hacé fork en GitHub: clickeá "Fork" en
#    https://github.com/Tomy-Niepo/AstroDojo

# 2. Cloná tu fork
git clone https://github.com/TU-USUARIO/AstroDojo.git
cd AstroDojo
pip install -r requirements.txt

# 3. Extraé los ejercicios e importalos
unzip new-exercises.zip -d new-exercises/
python import_exercises.py

# 4. Commit y push
git add exercises/
git commit -m "Add new exercises"
git push

# 5. Abrí un PR desde tu fork en GitHub
